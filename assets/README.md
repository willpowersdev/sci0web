# Preview artwork

The Sierra logo and King's Quest IV title artwork are rendered from the local
SCI version of King's Quest IV (1988). The logo comes from picture 700; the title
is a frame from the opening sequence, with the original 1.2 pixel aspect ratio.

Sierra's logo and game artwork belong to their respective owners and are not
covered by this repository's MIT licence. These PNGs are presentation images;
no playable game resources are included here.

Deploy this assets directory alongside index.html and dist/app.js. The sharing
metadata lives in the HTML so preview crawlers do not need JavaScript. Its image
paths are relative to the page; when the public URL is known, use the full public
image URL in both og:image and twitter:image for the broadest crawler support.
